# SocksAPI

SocksAPI is a platform that connects all your AI services in one place and lets you access their models through a single API key.

Inspired by the implementation of OpenRouter.

## Implementation So Far

- Base UI
- Provider brand icons
- Backend 
- Postgres DB
- Add services
  - Groq
  - DeepSeek
  - Custom providers (any OpenAI-compatible endpoint, key optional)
- Create unified API keys
- Playground
- Customer providers
